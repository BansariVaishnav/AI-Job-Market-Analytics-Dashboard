## 📌 Project Overview

This project is an interactive **Power BI dashboard** built using a dataset of **5,000+ AI and Data Science job postings**. The dashboard provides insights into hiring trends, salary distribution, skill demand, and recruitment patterns across multiple countries.

The objective of this project is to demonstrate **Business Intelligence, Data Visualization, Data Modeling, and DAX skills** by solving a real-world analytics problem.

---

## 🎯 Business Objectives

- Identify the most in-demand technical skills.
- Analyze salary trends across countries and job roles.
- Discover hiring patterns and recruitment trends.
- Compare remote, hybrid, and on-site job opportunities.
- Provide actionable insights for job seekers and recruiters.

# 📈 Dashboard Pages

## 1️⃣ Executive Overview
Provides a high-level summary of the job market.

### Insights

- Remote work distribution

## 2️⃣ Skills Analytics
Analyzes skill demand in the AI job market.

### Insights

## 3️⃣ Salary Analytics
Provides compensation insights.

### Insights

## 4️⃣ Recruitment Analytics
Analyzes hiring patterns and applicant trends.
